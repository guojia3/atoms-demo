## 6. 已知限制与非缺陷（如实记录）

- **HTTP + IP**：按猎头路线 C 属可接受交付；`Secure` Cookie 在 HTTP 下不启用是正确行为，不是缺陷。
- **UI 方向未实现**：题面未强制，按非缺陷记录；仅影响美观度自评。
- **Safari 未验证**：受浏览器工具限制，沿用 QA 记录为“未验证”，不虚报通过。
- **演示视频缺失**：题面未强制；猎头明确验收官不看自测视频。
- **评分由客户端沙箱上报**：恶意页面理论上可伪造指标；已列入说明文档风险。
- **单实例 SQLite/进程内限流/SSE 400 条**：演示规模足够，多实例需 Redis/Postgres。
- **旧 slug 页面 200 壳**：API 404、页面显示“可能已被作者下线”，用户体验可接受，文档表述需修正。
