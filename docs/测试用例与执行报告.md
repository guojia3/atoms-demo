### DEF-01 生成配额（已关闭）

- **原问题**：同一游客 8 并发生成全部 201，无任何限流。
- **复测**：默认配额 20/小时，21 并发 → 20×201 + 1×429，`Retry-After>0`；回归脚本将配额设为 3，验证第 4 次 429 且游客升级邮箱后仍共享同一配额。
- **证据**：`test/results/api.json` CON01；`test/results/regression.log` DEF-01。

### DEF-02 body 上限与错误码（已关闭）

- **原问题**：4.6MB body 与畸形 JSON 均 500。
- **复测**：默认 1MB 上限返回 413（文案“请求体过大（上限 1mb）”）；畸形 JSON 返回 400（“请求体不是合法的 JSON”）；回归脚本 128KB 覆盖同样通过。
- **证据**：`test/results/api.json` SEC03/SEC04；`regression.log` DEF-02a/b。

### DEF-03 安全响应头（已关闭）

- **原问题**：API/页面无 X-Content-Type-Options、X-Frame-Options、CSP、Referrer-Policy，且有 X-Powered-By。
- **复测**：API 与页面均含 5 类头（含 `frame-ancestors 'none'` 的 CSP、Permissions-Policy），`X-Powered-By` 已移除；375px/桌面浏览三页均无 CSP 拦截。
- **证据**：`regression.log` DEF-03；`api.json` SEC05；`mobile-*.png` 运行截图。

### DEF-04 Cookie Secure（已关闭，按示例部署不启用 Secure）

- **原问题**：`atoms_sid` 硬编码 `secure:false`。
- **复测**：`X-Forwarded-Proto=https` 时 `Secure+HttpOnly+SameSite=Lax`；HTTP 直连不加 Secure（避免 Cookie 被浏览器丢弃）。符合设计预期。
- **证据**：`api.json` SEC06；`regression.log` DEF-04。
- **注意**：示例部署为 HTTP + IP 直连，线上 `Secure` 不会下发，属已知限制而非缺陷；`HttpOnly + SameSite=Lax` 仍生效。若未来启用 HTTPS，代码会自动加 `Secure`，无需改动。

### DEF-05 跨站 Origin 校验（已关闭）

- **原问题**：`Origin: https://evil.example` 的 `POST /api/projects` 返回 201。
- **复测**：跨站 403；同源、无 Origin、`PUBLIC_ORIGIN` 白名单均 201。
- **证据**：`api.json` SEC08；`regression.log` DEF-05。

### DEF-07 分享页模板标注（已关闭）

- **原问题**：模板/回退版本在分享页 `mock=false`，显示“模型生成”。
- **复测**：Mock 模板 v1 分享 `mock=true`、`model=atoms-mock`；回退生成新版本 `source=restore` 后仍 `mock=true`。
- **证据**：`api.json` API38；`regression.log` DEF-07；375px 发布页截图为“内置示例（模板）”。

### DEF-08 停止终态（已关闭）

- **原问题**：停止瞬间 stopped 被收尾覆盖为 failed。
- **复测**：done=stopped，等待 6s 回放 snapshot=stopped，versions=0；失败收尾路径不再覆盖用户停止。
- **证据**：`test/results/resilience.json` EX07；`regression.log` DEF-08。
